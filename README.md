# Wearable Heart Rate Monitor

A c++ menu-driven program that simulates heart rate readings and checks whether they're normal based on the user's inputted age and chosen activity. 

## Team 
- Michael Morales
- Ella Goldman
- Rachel Hsu

## Build Instructions 
Requires a C++ compiler such as g++. 

From the repository root run:
```
g++ src/*.cpp -o heartmonitor
```
## Run Instructions 
```
./heartmonitor
```
